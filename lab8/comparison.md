**Тайлбар:** Файлын хэмжээ нь зөвхөн төслийн эх файлуудын хэмжээ; Bootstrap CDN болон Tailwind build-ийн хэмжээ энд ороогүй. Tailwind CLI build хийсний дараа `tailwind/output.css` хэмжээг нэмж харьцуул. Lighthouse-ийн оноог хоёр хуудсыг ижил төхөөрөмж, ижил горимоор Chrome DevTools → Lighthouse ашиглан хэмжиж бөглөнө.

**Дүгнэлт:** Bootstrap нь бэлэн navbar, card, validation болон theme механизмтай тул UI-г хурдан угсрахад тохиромжтой. Tailwind нь utility class-уудаар загварыг нарийн удирддаг бөгөөд HTML-ийн class жагсаалт урт болдог. Хоёр арга хоёулаа responsive 3 баганатай карт болон dark mode хэрэгжүүлж чадна.
